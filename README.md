# Masroof Lite v4 — مجموعات مرنة وحالات خاصة

نفس واجهة Masroof Lite الداكنة/البرتقالية المعتادة، تخزين **محلي داخل المتصفح**، من غير تسجيل دخول أو Supabase أو API. الموقع لا يزامن بين الموبايل والتابلت، حتى لو ثبتّه كاختصار.

## الجديد

- **المجموعات**: إضافة مجموعات/باقات بأي اسم وسعر افتراضي، وتعديل سعر المجموعة من الشهر المختار، وإيقاف المجموعة مع الاحتفاظ بسجلاتها السابقة. حذف المجموعة نهائيًا متاح لو لم يُضَف لها أي طالب.
- **الطلبة والعملاء**: تعديل الاسم أو نقل الطالب لمجموعة ثانية بدءًا من الشهر المعروض، إضافة فردية أو جماعية، إيقاف وإعادة تفعيل. الحذف النهائي مسموح فقط لمن **لا توجد له دفعات مسجلة**. إيقاف طالب يوقف استحقاق الشهور التالية ويحفظ القديم.
- **حالات خاصة**: عادي بسعر المجموعة، أو سعر خاص، أو إعفاء كامل. تطبيق التغيير لشهر واحد أو من الشهر المعروض وما بعده. **المعفى مستحقه صفر ولا يدخل في المتأخرات**. المدفوعات السابقة لا تُحذف عند تغيير السعر، ويظهر تنبيه لو صار المقبوض أعلى من المستحق.
- **تحصيلات**: حالات مدفوع بالكامل، جزئي، معفى، لم يدفع، وملخص للمستحق والمقبوض والمتبقي لكل مجموعة. تاريخ استلام الأموال منفصل عن الشهر المستحق.
- **Font Awesome Free**: أيقونات SVG فعلية من مجموعة Font Awesome Free 6.7.2، ومضمّنة محليًا في `src/fa-icons.js`؛ من غير مكتبات UI أو تحميل من CDN. Font Awesome by Fonticons, Inc., licensed under CC BY 4.0 for icons: https://fontawesome.com/license/free.
- كل وظائف v3 موجودة: إضافة/تعديل/تكرار المصروفات، تاريخ المصروف، نسخ المصروفات، مقارنة الشهور، التحويش، تذكير الـBackup، واستيراد/تصدير JSON.

## مهم جدًا قبل التحديث

1. افتح **رابط Masroof الحالي من الجهاز والمتصفح اللي عليه بياناتك**.
2. ادخل **الإعدادات → تنزيل نسخة JSON**، واتأكد بنفسك من الملف في Downloads. احفظ نسخة إضافية على فلاشة أو مكان آمن. **لا ترفع ملف الـBackup الشخصي على GitHub**؛ لأنه يحتوي أسماء الطلبة وبيانات مالية.
3. يفضَّل تجربة v4 محليًا/على بيانات تجريبية قبل تحديث الرابط الأساسي.
4. افتح نفس رابط Vercel بعد النشر على **نفس المتصفح**. v4 سيبحث أولًا عن `masroof-lite-v4`، وإن لم يجده سيقرأ بيانات v3 الموجودة تحت `masroof-lite-v2` (أو `masroof-ui-v1`)، ويحوّل المجموعات القديمة إلى مجموعات قابلة للتعديل. **لن يمسح مفتاح v3 الأصلي.**
5. لو الموقع ظهر فاضي بعد النشر: **لا تضف بيانات جديدة**. افحص الرابط والمتصفح ثم استخدم **استرجاع نسخة JSON** من الإعدادات. استيراد نسخة v3 القديمة مدعوم. الاستيراد يستبدل حالة v4 الحالية بعد تأكيدك، ويبدأ تنزيل نسخة قبل الاستبدال — تأكد من حفظ الملف.

> **مهم:** `localStorage` ليس حماية من فقد البيانات، وفتح Masroof على جهاز جديد لا يعرض البيانات المسجلة على جهاز آخر. في حال استخدام والدك للموقع، الأفضل يبدأ من جهاز واحد ويصدّر Backup أسبوعيًا. ولو أراد نقل البيانات من جهاز لآخر فيمكن تصدير JSON واستيراد الملف يدويًا بعد التأكد أنه لا يستبدل سجلات جديدة على الجهاز الآخر.

## تشغيل المشروع

من داخل مجلد `masroof-app`:

```bash
npm install
npm run dev
```

لتشغيل اختبارات البيانات (14 اختبار):

```bash
npm test
```

للتحقق من تجميع المشروع قبل النشر:

```bash
npm run build
```

## تحديث GitHub من المتصفح — بدون Git

1. فك ضغط ZIP.
2. افتح **نفس** مستودع GitHub القديم، وليس مستودعًا جديدًا.
3. من Add file → Upload files، ارفع محتويات مجلد `masroof-app` مع الحفاظ على المسارات، خصوصًا `src/ledger.js` و`src/fa-icons.js` و`src/App.jsx` و`src/styles.css` و`public/sw.js` و`package.json` و`index.html`.
4. **لا ترفع** `node_modules` أو `dist` أو ملفات النسخ الاحتياطية `.json` الخاصة ببياناتك.
5. Commit على `main`. إذا Vercel مربوط بنفس الفرع سيعيد النشر تلقائيًا. عند فشل النشر افتح Build Logs. ولو كان فيه `package-lock.json` قديم جدًا لا يطابق `package.json`، حدّثه باستخدام `npm install` محليًا ثم ارفعه أيضًا.
6. افتح الموقع على الجهاز الأصلي، وتأكد أن المجموعات والطلبة والدفعات والمصاريف ظهرت. اختبر إضافة **طالب تجريبي** معفي ثم امسحه إن لم تكن له دفعات.

## كيف حُفظ التاريخ المالي؟

تتبع v4 سجلًا لتغير سعر المجموعة والطالب **بداية من شهر التغيير**، ولا يعيد احتساب الشهور السابقة بالسعر الجديد. ويحتفظ بسجل المجموعة عند نقل الطالب. بيانات v3 الأصلية لا تحمل تاريخ التغيرات القديمة في الأسعار؛ لذا يُفترض في الترحيل أن السعر الأخير الموجود في v3 كان السعر المطبق قديمًا أيضًا. هذا هو الحد المتاح للحفاظ على البيانات الموجودة بدون اختلاق تاريخ أسعار غير مسجل.

## الاختبارات

- اختبارات Node لعمليات الترحيل، الأرصدة المستحقة، الإعفاء، السعر المؤقت، تغيير المجموعة، الإيقاف، وعدم حذف السجلات المرتبطة بدفعات **نجحت (14/14)**.
- فحص بناء JSX نحويًا باستخدام TypeScript نجح دون أخطاء.
- **تعذر اختبار `vite build` الحقيقي في بيئة الإعداد** بسبب عدم الوصول إلى سجل npm، كما تعذرت معاينة React التفاعلية في المتصفح الآلي المتاح. اختبر التشغيل الفعلي على جهازك قبل تحديث الموقع المنشور.
