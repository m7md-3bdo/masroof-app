# مصروف — Masroof Lite

نسخة خفيفة وسريعة من موقع مصروف بـ React وVite وCSS عادي، من غير Supabase ومن غير مكتبات UI.

## الجديد

- إضافة مصروف بالمبلغ والوصف الاختياري والتاريخ.
- التاريخ ظاهر تحت كل مصروف، وزر **نسخ مصروفات الشهر** بينسخ القائمة بالتواريخ والإجمالي؛ ينفع لصقها في واتساب أو نوتس.
- شهريات أولى وتانية ثانوي، إضافة طالب أو أسماء دفعة بالجملة، وتحصيل كامل أو جزئي. تاريخ القبض منفصل عن شهر استحقاق الشهرية.
- تبويب بسيط للتحويش، مع تحويل مبلغ للتحويش أو إرجاعه للصرف من غير حسابه كمصروف.
- ضبط الرصيد المتاح والتحويش الفعلي في أي وقت (خصوصًا لو بدأت في منتصف الشهر).
- نسخة احتياطية JSON واستيرادها من الإعدادات.
- أيقونة تطبيق بألوان فحمي وبرتقالي وملف `manifest.webmanifest` للاختصار على الموبايل، مع Service Worker بسيط للتصفح بدون إنترنت بعد تحميل ملفات التطبيق.
- يقرأ بيانات الموقع القديمة المحفوظة بمفتاح `masroof-ui-v1` على نفس الجهاز والمتصفح إن وُجدت.

## التشغيل على الكمبيوتر

```bash
npm install
npm run dev
```

لفحص إنتاج Vercel قبل الرفع:

```bash
npm run build
```

## التحديث من GitHub بدون Git

1. خُد نسخة احتياطية من الموقع القديم أولًا لو كنت سجلت عليه حاجة مهمة.
2. افتح مستودع `masroof-app` في GitHub.
3. من `Add file` اختار `Upload files`، واسحب **المحتويات داخل** فولدر `masroof-app` من الملف المضغوط، مش فولدر `masroof-app` نفسه ومش ملف ZIP.
4. تأكد إن `src/App.jsx` و`src/styles.css` و`index.html` و`package.json` في نفس أماكنهم السابقة، وإن فولدر `public` فيه manifest والأيقونات.
5. اعمل Commit للتغييرات على `main`. لو Vercel مربوط بالمستودع هينشر نسخة جديدة تلقائيًا.
6. افتح الموقع بعد النشر، ولو النسخة القديمة ظهرت اعمل Refresh. لو أيقونة الاختصار القديمة فضلت، احذف اختصار الشاشة الرئيسية وثبتّه تاني.

> **تحذير مهم:** التخزين محلي في `localStorage` وليس مزامنة سحابية. تغيير الجهاز أو مسح بيانات الموقع أو استخدام وضع Incognito قد يؤدي لفقد البيانات. احفظ نسخة JSON دورية في مكان آمن مثل مجلد على جهازك ونسخة في مكان آخر. النسخة الاحتياطية قد تحتوي أسماء طلبة ومعلومات مالية، فلا تشاركها علنًا.

## إعداد الرصيد للمرة الأولى

من **الإعدادات ← ضبط الرصيد المتاح والتحويش** اكتب:
- الفلوس الموجودة معاك الآن واللي ممكن تصرفها (بدون التحويش)
- الفلوس اللي محوشها بالفعل

التطبيق هيظبط نقطة البداية حسب العمليات المسجلة وقتها، حتى لا يخصم مصاريف سجلتها قبل ضبط الرصيد مرتين.

## ملفات مهمة

- `src/App.jsx`: التطبيق والمنطق.
- `src/styles.css`: التصميم، متجاوب مع الموبايل.
- `public/icons/masroof-192.png` و`masroof-512.png`: أيقونة الاختصار.
- `public/manifest.webmanifest`: اسم ولون وأيقونات التطبيق.
- `public/sw.js`: حفظ ملفات التطبيق للتصفح عند انقطاع الاتصال (بعد فتحه أونلاين أولًا).
