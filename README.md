# مصروف — Masroof

تطبيق React + Vite عربي لربط شهريات الطلبة بالمصاريف الشخصية، بدون أي مكتبة UI أو CSS framework.

## التشغيل

افتح المشروع في VS Code، ثم نفّذ:

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في Terminal (غالبًا http://localhost:5173).

## الوظائف في هذه النسخة

- فصل أولى ثانوي (150 جنيه افتراضيًا) عن تانية ثانوي (200 جنيه افتراضيًا).
- إضافة طالب، أو إضافة مجموعة أسماء دفعة واحدة، وتعديل اسمه أو قيمة الشهرية.
- اختيار الشهر وتسجيل شهرية كاملة/جزئية وحفظ تاريخ الاستلام الفعلي.
- متابعة المتبقي والمدفوع، وإيقاف الطالب بدءًا من شهر محدد دون مسح تاريخه.
- تسجيل المصروفات الصغيرة بوصف اختياري وتصنيف ونشاط منفصلين.
- لوحة مالية وتقارير بالرسوم الخفيفة، ونسخ الملخص وتصدير صورة PNG وCSV.
- تصدير/استيراد نسخة احتياطية JSON من كل البيانات.

## تنبيه مهم بخصوص حفظ البيانات

هذه نسخة واجهة وظيفية **محلية**: البيانات تحفظ في `localStorage` على **نفس المتصفح والجهاز** فقط. قد تضيع إذا مسحت بيانات المتصفح، ولا تتزامن تلقائيًا بين الموبايل واللاب. استخدم زر **نسخة احتياطية** بانتظام. قبل الاعتماد على التطبيق للمبالغ الحقيقية، يجب إضافة قاعدة بيانات سحابية (مثل Supabase)، وتسجيل دخول وصلاحيات، واستراتيجية نسخ احتياطي على الخادم.

لا تُدخل أسماء أو بيانات حساسة لأشخاص آخرين على جهاز مشترك قبل إضافة تسجيل الدخول الآمن.

## ملاحظات مالية

- **الشهريات المطلوبة للشهر** تختلف عن **المقبوض نقدًا خلال الشهر**.
- تسجيل شهرية أكتوبر بتاريخ استلام في نوفمبر يخصم مديونية أكتوبر، لكنه يحتسب من المقبوضات النقدية في نوفمبر.
- «صافي حركة الشهر» = كل المدفوعات التي **استُلمت فعليًا خلال الشهر** ناقص مصروفات نفس الشهر. ليس الرصيد الكلي للحساب؛ لأن الرصيد الافتتاحي والتحويلات والمدخرات ليست جزءًا من هذه النسخة.
- الأرقام الأولية صفر، ولن يتم اختلاق أسماء لطلبتك. استخدم إضافة الأسماء بالجملة.

## معاينة التصميم

تم تجهيز صورة منفصلة لمعاينة شكل الصفحة. ملف `design-preview.html` إن وجد هو نموذج شكلي ثابت ببيانات تخيلية وليس جزءًا من التطبيق الفعلي.
