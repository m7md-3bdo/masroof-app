# Masroof Lite — تحديث الميزات الأربع

نفس واجهة Masroof Lite الفحمي والبرتقالي، ونفس التخزين المحلي، وبدون أي مكتبات UI أو خدمات خارجية.

## الجديد

1. **تكرار مصروف**: في صف كل مصروف فيه زر سهمين دائريين. الضغط عليه يضيف نسخة جديدة بنفس المبلغ والاسم والتصنيف، لكن **بتاريخ اليوم ومعرّف جديد**. المصروف الأصلي لا يتغير. لو بتستعرض شهر قديم، الموقع يفتح الشهر الحالي ليعرض المصروف الجديد.
2. **تذكير النسخة الاحتياطية**: يظهر تنبيه بسيط في الرئيسية والإعدادات عند وجود بيانات مهمة وعدم تسجيل محاولة تنزيل نسخة خلال آخر 7 أيام. زر «نزّل نسخة» يبدأ تنزيل ملف JSON، وزر «بعدين» يخفي التذكير ليوم واحد. **لا يمكن للموقع التأكد أن الملف نزل فعليًا، فلازم تتأكد من وجوده في Downloads.**
3. **مقارنة شهرين**: أسفل قائمة المصاريف في تبويب «المصاريف» قسم صغير يقارن الشهر المختار بالشهر السابق. لو الشهر المختار هو الشهر الحالي، المقارنة تكون من يوم 1 حتى اليوم نفسه في الشهر السابق، عشان الشهر الناقص ما يبانش قليل بالخطأ.
4. **تحسين أيقونات المصاريف**: أيقونات SVG خفيفة ومختلفة للمواصلات، الكلية، الأكل، التسوق، الاشتراكات، الخروجات، الرياضة، الصحة، والمتفرقات. لو المصروف تحت «متفرقات»، الاسم نفسه يساعد في تحديد الأيقونة، من غير إرسال بياناتك لأي خدمة.

## حفاظ البيانات — مهم جداً

- **مفتاح التخزين ما اتغيرش**: `masroof-lite-v2`.
- **هيكل البيانات ما اتغيرش**: ما زالت `students`, `payments`, `expenses`, `savings`, `settings`.
- **النسخة مش بتسحب بيانات أوتوماتيكيًا من موبايل لجهاز مختلف**: كل متصفح له بياناته الخاصة.
- **قبل ما ترفع التحديث**: افتح رابط الموقع الحالي على الجهاز اللي سجلت عليه مصاريفك بالفعل، ادخل «إعدادات» ← «تنزيل نسخة JSON»، وبعد التنزيل افتح Downloads واتأكد إن الملف موجود. احتفظ به في مكان آمن بعيدًا عن المستودع GitHub لأنه يحتوي بيانات مالية وأسماء طلبة.
- **لو بعد التحديث ظهرت بيانات فاضية**: ما تدخلش بيانات جديدة، افتح نفس المتصفح ونفس رابط Vercel القديم، وجرّب «إعدادات» ← «استرجاع نسخة» باستخدام ملف JSON.

## تشغيل المشروع

افتح Terminal في فولدر `masroof-app`:

```bash
npm install
npm run dev
```

لفحص المنطق البسيط (بدون مكتبات):

```bash
npm test
```

ولفحص إنتاج Vite بعد تنزيل المكتبات:

```bash
npm run build
```

## تحديث GitHub بدون Git

1. فك الضغط.
2. في GitHub افتح **نفس** المستودع: `m7md-3bdo/masroof-app`، لا تعمل مستودع جديد.
3. من **Add file → Upload files**، اسحب من داخل `masroof-app` المجلدين `src` و `public` وملفات `index.html` و `package.json` و `README.md` و `.gitignore` إن كان موجودًا. لا ترفع `node_modules` أو `dist` أو ملفات النسخة الاحتياطية JSON.
4. وافق على استبدال الملفات الموجودة بنفس الاسم والمسار، واضغط **Commit changes** لفرع `main`.
5. Vercel، إذا كان ما زال مربوطًا بفرع `main`، سيعيد النشر تلقائيًا. افتح **نفس رابط موقعك القديم** وجرب تحديث الصفحة. ممكن يحتاج اختصار الموبايل لإغلاق التطبيق وفتحه بعد التحديث بسبب Service Worker.
6. جرّب تكرار مصروف **تجريبي** وتأكد إنه ظهر بتاريخ النهارده، وبعدها احذفه. راجع مقارنة الشهور وتنبيه النسخ الاحتياطية.

### ما تم اختباره

نجحت اختبارات Node السبعة الخاصة بتكرار المصروف، حساب مقارنة الشهور (بما فيها يناير)، اكتشاف الأيقونة، ومهلة تذكير النسخ الاحتياطية. تم فحص JSX نحويًا. لم يكتمل تشغيل `vite build` في بيئة الإعداد بسبب عدم توفر حزم npm هنا؛ لو ظهر خطأ في نشر Vercel، راجع Build Logs.

> التخزين المحلي **ليس Backup**. مسح بيانات الموقع أو تغيير الجهاز أو العمل في نافذة خفية يمكن أن يفقد السجل. نزّل ملف JSON واحتفظ بنسخة منفصلة بشكل دوري.
